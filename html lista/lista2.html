Protocolo HTTP

HTTP significa HyperText Transfer Protocol. É um protocolo utilizado para realizar a comunicação entre o navegador e os servidores na Web.

Como funciona o HTTP?

Quando acessamos um site, o navegador envia uma requisição, chamada Request, para um servidor. O servidor recebe essa requisição, processa as informações e envia uma resposta, chamada Response.

Navegador → Request → Servidor

Navegador ← Response ← Servidor

Exemplo de uma requisição HTTP

GET /index.html HTTP/1.1

Host: exemplo.com

User-Agent: Chrome

Accept: text/html

Campos da requisição

  • GET: método utilizado para solicitar um recurso.
  • /index.html: recurso que está sendo solicitado.
  • HTTP/1.1: versão do protocolo HTTP.
  • Host: endereço do servidor que será acessado.
  • User-Agent: identifica o navegador utilizado.
  • Accept: informa o tipo de conteúdo que o navegador aceita.

Exemplo de uma resposta HTTP

HTTP/1.1 200 OK

Content-Length: 1250

Campos da resposta

  • HTTP/1.1: versão do protocolo utilizada.
  • 200 OK: indica que a requisição foi realizada com sucesso.
  • Content-Type: informa o tipo de conteúdo enviado pelo servidor.
  • Content-Length: informa o tamanho do conteúdo enviado.

Capturando uma requisição

Para capturar uma requisição HTTP no navegador, podemos utilizar as ferramentas de desenvolvedor.

  1. Abrir o navegador.
  2. Pressionar F12.
  3. Acessar a aba Network ou Rede.
  4. Recarregar a página.
  5. Clicar em uma das requisições.
  6. Acessar a seção Headers.
